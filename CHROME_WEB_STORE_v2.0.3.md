# AI Chat Printer v2.0.3 — Chrome Web Store Güncelleme İçeriği

> Hazırlanma tarihi: 29.09.2026

Mağaza başlığı, açıklamalar, tek amaç, veri kullanımı, izin gerekçeleri, görseller ve gizlilik adresleri `CHROME_WEB_STORE_v2.0.2.md` ile aynıdır.

## Sürüm Notu Alanı

v2.0.3, ChatGPT yanıtı tamamlandığı hâlde görülebilen “henüz yanıt yazıyor” uyarısını düzeltir. Güncel ChatGPT mesaj ve görsel yapısını, SVG/Mermaid görsellerini ve büyük konuşmaları destekler. Güncelleme sonrası açık sekmelerde bağlantıyı otomatik yeniler.

## İzin ve Gizlilik Değişikliği

`unlimitedStorage` izni eklendi: büyük konuşmaların 10 MB yerel depo sınırına takılmadan yazdırılması için kullanılır. API izinleri `activeTab`, `storage`, `unlimitedStorage`, `clipboardWrite`; host erişimi yalnız Gemini, Claude, ChatGPT ve Grok alan adlarıyla sınırlıdır. Konuşmalar cihaz dışına gönderilmez.
